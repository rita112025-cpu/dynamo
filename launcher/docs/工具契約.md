# 工具契約

新工具要接進批次佇列，只改 `launcher/tools.json`，並準備一支手動模式的 `.dyn`。啟動器不會執行圖形，也不會寫入 `.dyn`。

正式結構見：

- `launcher/schemas/tool.schema.json`
- `launcher/schemas/task-config.schema.json`
- `launcher/schemas/run-log.schema.json`
- `launcher/examples/task-config.example.json`

檢查由 `launcher/queue/DynamoQueue.ps1` 執行。下面兩支工具只是契約範例，儲存庫裡還沒有它們的 `.dyn`，不要寫進 `tools.json`。

## 模型檢查（唯讀，沒有寫入開關）

```json
{
  "id": "model-inspector",
  "name": "模型檢查",
  "dyn": "模型檢查/ModelInspector.dyn",
  "supportsDryRun": false,
  "inputs": [
    {
      "name": "scope",
      "type": "string",
      "label": "檢查範圍",
      "required": false,
      "default": "all"
    }
  ]
}
```

## DWG 匯入 Revit（有寫入開關，預設試跑）

```json
{
  "id": "dwg-import",
  "name": "DWG 匯入 Revit",
  "dyn": "DWG匯入/DwgImport.dyn",
  "supportsDryRun": true,
  "dryRunInput": "run",
  "inputs": [
    {
      "name": "dwg",
      "type": "file",
      "label": "DWG 檔",
      "required": true
    },
    {
      "name": "run",
      "type": "boolean",
      "label": "寫入（False = 試跑）",
      "required": false,
      "default": false,
      "writesModel": true
    }
  ]
}
```

`run` 的預設必須是 `false`。任務設定要把 `run` 設成 `true` 時，同一份設定的 `confirmWrite` 也必須是 `true`。畫面還會再問一次。

## 輸入型別

| type | 值 |
| --- | --- |
| `string` | 文字。可用 `enum` 限制可選值 |
| `boolean` | `true` 或 `false`。不接受 `"false"` 或 `0` |
| `integer` | 整數 |
| `number` | 數字 |
| `directory` | 資料夾路徑 |
| `file` | 檔案路徑 |
| `string-list` | 文字清單。空清單要寫 `[]` |

選填輸入必須有 `default`。必填輸入可以不給預設，讓任務設定自己填。

## 執行紀錄

每個工作一筆。`manualMode` 固定是 `true`，`graphExecutedByLauncher` 固定是 `false`。狀態是 `planned`、`opened-manual`、`dry-run`、`written`、`failed`、`skipped`。計數只有 `files`、`changed`、`skipped`、`failed`。
