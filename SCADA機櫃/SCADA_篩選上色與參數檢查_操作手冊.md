# SCADA 圖元上色：篩選設定、參數檢查與跨站轉移

**日期：** 2026-11-08（同日更新：加入 Dynamo 批次流程與試跑結果）
**環境：** Autodesk Revit **2025.5**、Dynamo（CPython3）
**參考檔案：** `DN-ESC-0400-0000 v8.3.rvt`（各車站 SCADA 模型）
**用途：** 說明 Revit 如何決定顏色、SCADA 篩選的設定方式、建模時要填的參數，以及如何用 Dynamo 批次把設定套到多個車站檔案。

---

## 1. Revit 如何決定顏色

同一個圖元在視圖裡的顏色，依下列優先順序決定（上面的蓋過下面的）：

| 優先 | 來源 | 位置 |
|---|---|---|
| 1 | 個別圖元取代 | 右鍵圖元 → 在檢視中取代圖形 → 依圖元 |
| 2 | 篩選（過濾器） | 可見性/圖形 → 篩選頁籤 |
| 3 | 模型品類取代 | 可見性/圖形 → 模型品類 → 取代 |
| 4 | 系統類型本身的設定 | 專案瀏覽器 → 族群 → 風管系統 → 類型內容 → 圖形取代 |
| 5 | 材料的著色顏色 | 管理 → 材料 |

視圖若套用**視圖樣板**，樣板會鎖住上述視圖層級的設定，要改須改樣板。

### 1.1 本專案風管系統顏色（線條顏色，來自系統類型）

| 系統類型 | 線條顏色 (RGB) | 備註 |
|---|---|---|
| SUPPLY AIR（供風） | 128-255-128（淺綠） | 已確認 |
| EXHAUST AIR（排氣） | 0-128-255（藍） | 已確認 |
| SUPPLY A/C | 青色 (Cyan) | 數值未顯示，待確認 |
| 其他系統 | 未查 | FRESH AIR、RETURN AIR、SMOKE EXHAUST AIR 等 |

### 1.2 SCADA（中央監控系統，代號 ESC）

- 顏色：**RGB 12-100-47（深綠）**
- SCADA 的元件不是風管系統，所以**用篩選上色**，不是系統類型。

## 2. SCADA 篩選設定

目前檔案內有兩個過濾器：

| 過濾器 | 規則 | 套用品類（截圖可見） |
|---|---|---|
| `SCADA` | 服務類型 等於 SCADA | 電管、電管配件、電纜架、電纜架配件 |
| `SCADA_電氣設備` | 備註 等於 SCADA | 電氣設備、電氣裝置、電線、風管系列、牆、天花板、家具等 |

在視圖的可見性/圖形取代 → 篩選頁籤中，`SCADA` 已啟用且可見，投影/表面的**樣式**為深綠。

### 2.1 設定時的注意事項

1. **「等於」要完全一致**：`SCADA `（後面多空格）或 `scada` 都抓不到。可改用「包含」提高容錯。
2. **線也要設顏色**：目前只設了表面樣式，線欄位空白，隱藏線模式下只看得到線條，會沒有 SCADA 顏色。建議線顏色也設成 12-100-47。
3. **篩選順序**：同一圖元符合多個過濾器時，清單上方優先，SCADA 要排在其他系統過濾器之前。
4. **代號統一**：規則寫的是 `SCADA`，專案代號是 `ESC`，須決定以哪個為準，兩邊要同步。
5. **機櫃的備註**：機櫃腳本（`scada_racks.py`）會把備註寫成「站點 房間 機櫃類型」，不是 `SCADA`，`SCADA_電氣設備` 過濾器抓不到這些機櫃。建議改用「族群名稱 包含 `SCADA_機櫃`」的規則。

## 3. 建模時要填的參數檢查清單

### A. 電管、電管配件、電纜架、電纜架配件

對應過濾器：`SCADA`

- [ ] 性質面板 **服務類型** 填 `SCADA`
- [ ] 文字完全一致：全大寫、前後無空格、無全形字元
- [ ] 配件（彎頭、三通等）的服務類型也有填
- [ ] 品類有被勾在過濾器內

### B. 電氣設備、電氣裝置、電線與其他圖元

對應過濾器：`SCADA_電氣設備`

- [ ] 性質面板 **備註 (Comments)** 填 `SCADA`
- [ ] 文字完全一致
- [ ] 品類有被勾在過濾器內，其他品類（如特製設備）要先確認有沒有勾
- [ ] 備註是**實例參數**，每個圖元都要填，不是改族群類型就好

### C. 通用檢查

- [ ] 視圖已套用 `SCADA` 視圖樣板，樣板內含 SCADA 過濾器且為「可見」
- [ ] SCADA 過濾器位置夠前，不會被其他過濾器蓋掉
- [ ] 過濾器的線與表面樣式顏色都是 RGB 12-100-47
- [ ] 代號與規則文字統一（SCADA 或 ESC）

### D. 檢查有沒有漏填

1. **反向檢查**：在 3D 視圖暫時關閉 SCADA 過濾器可見性，剩下沒被藏起來的圖元裡，若有屬於 SCADA 的，就是漏填的。
2. **明細表**：建一張包含「服務類型」「備註」欄位的明細表，依品類分組，檢查空值。
3. **選取檢查**：選一個 SCADA 圖元，用「選取全部實例」確認數量合理。
4. **腳本重跑**：用 5.4 的腳本 dry run，「將填」都是 0 就代表沒有漏填。

## 4. 手動批次填寫（單一檔案）

數量不多時，在 3D 視圖直接手動批次：

1. 框選或 Ctrl 加選 SCADA 圖元。
2. 右下角漏斗（篩選選取項目）只勾電管、電管配件、電纜架、電纜架配件 → 性質面板 **服務類型** 填 `SCADA` → 套用。
3. 再框選一次，漏斗只勾電氣設備、電氣裝置、電線等 → **備註** 填 `SCADA` → 套用。
4. 確認圖元變成深綠；沒變綠的檢查是否漏填或多空格。

提醒：框選前先確認視圖裡沒有其他專業的圖元；備註原本已有內容時不要覆蓋；結束放置線指令時按 `Esc`。

## 5. 用 Dynamo 批次處理多個車站檔案

### 5.1 兩支工具

| 工具 | 位置 | 做什麼 |
|---|---|---|
| `BatchCopyViewTemplates.dyn` | `D:\Update Log\Dynamo_BatchViewTemplate\` | 把來源檔的視圖樣板（含它用到的過濾器）複製到資料夾內每個 `.rvt` |
| `BatchFillScadaParams.dyn` | `D:\SCADA_主題導覽\01_BIM model\SCADA_機櫃_Dynamo\批次填參數\` | 對資料夾內每個 `.rvt`，填電管、電纜架的服務類型與設備、電線的備註 |

兩支工具的節點相同：Directory Path、Code Block、True/False 開關、Python 節點、Watch。**開關 False 是試跑，True 才會寫入並存檔。**

### 5.2 建議順序

1. 用 `BatchCopyViewTemplates` 把 `SCADA` 樣板和過濾器複製到各車站檔案。
2. 用 `BatchFillScadaParams` 填服務類型與備註。
3. 每個檔案的 3D 視圖套用 `SCADA` 視圖樣板，確認顏色。

### 5.3 BatchCopyViewTemplates 操作

1. Revit 先開**來源檔**（有 `SCADA` 樣板，例如 `DN-ESC-0400-0000 v8.3.rvt`）。來源檔不能在目標資料夾內，目標檔也不能同時開著。
2. 「管理 → Dynamo」開啟 `.dyn`；Code Block 填 `["SCADA"];`；Directory Path 選目標資料夾。
3. 開關 False 先試跑：Watch 應顯示 `Source templates (1): SCADA`，每個檔案一行 `[DRY RUN]`。若顯示 `NOT FOUND in source`，代表目前開的檔案沒有這個樣板。
4. 改 True 執行，每個檔案顯示 `[OK]` 與 `added: SCADA` 或 `overwritten: SCADA`。
5. 樣板只是複製進去，**不會自動套到視圖**（除非原本就有視圖用同名樣板）；到各檔案 3D 視圖的性質面板，把「視圖樣板」選 `SCADA`。
6. 目的檔若已有同名過濾器，程式採「保留目的檔版本」，顏色不會被覆蓋，需到來源檔核對。

### 5.4 BatchFillScadaParams 操作

Revit 先開任一專案檔（不能是目標資料夾裡的檔案），開啟 `.dyn`，Directory Path 選資料夾，Code Block 填 `"SCADA";`。

**填值規則（不會破壞資料）：**

| 現況 | 處理 |
|---|---|
| 空白 | 填 `SCADA` |
| 大小寫或空格不同（`scada`、`SCADA `） | 修正成 `SCADA` |
| 已是 `SCADA` | 不動 |
| 其他非空內容 | **保留不動**，報告列出範例 |
| 無此參數或唯讀 | 只計數，不改 |

**涵蓋範圍：** 電管、電管配件、電纜架、電纜架配件（服務類型）；電氣設備、電氣裝置、電線（備註）。要加品類，在腳本的 `RULES` 加一行。

**防呆：** 只處理檔名含 `-ESC-` 的檔案，其他顯示 `[SKIP file name has no '-ESC-' - not a SCADA file]`。要改條件，改腳本最上方的 `FILE_NAME_MUST_CONTAIN`，設成空字串就不檢查。

**流程：**

1. 開關 False：每個檔案會被開啟、計數後關閉，**不存檔**。Watch 每個品類一行：將填、修正、原本就是、保留他值、無此參數或唯讀、失敗。
2. 數量合理再改 True：寫入並存檔（工作共享檔會同步到中央並釋放）。
3. 重跑一次 dry run 驗證，「將填」應全部是 0。

**注意：**

- 工作共享檔會開啟全部工作集，避免漏元素；被別人借用的元素寫不進去，計入「失敗」。
- 存檔時 Revit 會在同資料夾留下 `.0001.rvt` 備份，腳本會自動跳過這種檔名，確認無誤後再自行清除。
- 目前開著的檔案不會被處理。

### 5.5 試跑結果（2026-11-08）

**第一次（資料夾 `VT_Test`，內容是其他專業模型）：** 資料夾裡是機廠行政大樓的通訊、電氣、自動收費、消防、空調、月台門、給排水、供電、號誌、結構模型。若用 True 跑，電氣模型的 640 個電纜架、556 個配件、414 個設備、1336 個裝置、3503 條電線會被誤標為 SCADA。因此加入檔名防呆，並確認：

- 參數都抓得到（「無此參數或唯讀」為 0）。
- 別的專業已填的值（`通訊`、`Telecom`、`Power`、`號誌`）會被保留。

**第二次（車站資料夾內的 3 個 SCADA 檔，為實際作業檔，不是測試複本）：** 以下三個檔案已實際寫入並存檔。

| 檔案 | 電管 | 電管配件 | 電纜架 | 電纜架配件 | 電氣設備 |
|---|---|---|---|---|---|
| `DN-ESC-SB10-0000-v1.rvt` | 0 | 0 | 18 | 17 | 4 |
| `DN-ESC-SB12-0000-v1.rvt` | 2 | 3 | 11 | 8 | 4 |
| `DN-ESC-SB15-0000_v1.rvt` | 0 | 0 | 10 | 9 | 1 |

上表為 dry run 的「將填」數量，「保留他值」「無此參數或唯讀」「失敗」皆為 0；電氣裝置與電線為 0。正式寫入後重跑，三個檔案都顯示 `[OK nothing to change]`。

**樣板複製：** `BatchCopyViewTemplates` 對三個檔案都顯示 `added: SCADA`。SB10、SB12、SB15 套用 `SCADA` 樣板後，電纜架、配件、機櫃與設備都上了綠色，三站皆已目視確認。

### 5.6 常見問題

| 現象 | 原因與處理 |
|---|---|
| `NOT FOUND in source` | 目前開著的檔案沒有該名稱的視圖樣板；改開來源檔，名稱要一字不差 |
| `SKIP already open or loaded as link` | 目標檔正開著或被連結；先關閉或卸載連結 |
| `SKIP version mismatch` | 檔案不是 Revit 2025.5 存的 |
| `ERROR ... The model is transmitted` | 中央檔被傳送過，無法建立本機副本；非 SCADA 檔案，已被防呆跳過 |
| 切換 Revit 檔案後 Dynamo 讀到舊檔 | 關閉 Dynamo 分頁後重新開啟 |
| Watch 的長行被截斷 | 拉大 Watch 節點，或直接貼出整個 List；腳本內建寫入 `%TEMP%\BatchFill_last_report.txt` 的功能，試跑時未生效 |
| 重新開啟 `.dyn` 前 | 舊分頁關閉時不要存檔，否則會蓋掉新版腳本 |

## 6. 手動轉移：「轉移專案標準」

不想用 Dynamo 時，可用 Revit 內建功能：

1. 同時開啟**已完成的標準檔案**與**要設定的車站檔案**，後者為作用中視窗。
2. **管理 → 轉移專案標準**（「設定」群組）。
3. 「複製自」選標準檔案，先按「全部不選」，再勾：**視圖篩選**（`SCADA`、`SCADA_電氣設備`）、**視圖樣板**，需要時加勾「風管系統」。
4. 按確定；遇到同名項目選「覆寫」。
5. 到目標檔案的 3D 視圖套用視圖樣板。
6. 依第 3、4 節填寫參數並檢查。

標準檔案要先確認設定是對的；工作共享檔批次處理時不要直接動到中央檔。

## 7. 設定會不會「跑掉」

| | 改系統類型 | 篩選（過濾器） |
|---|---|---|
| 存在哪 | 專案的系統類型，跟著風管走 | 存在視圖或視圖樣板，不跟圖元走 |
| 影響範圍 | 整個專案所有視圖 | 只有套用它的視圖 |

匯進別人專案時：

1. **複製貼上**：對方若有同名系統類型，會用對方的設定；過濾器不會跟著過去。
2. **Revit 連結**：預設「依主體視圖」，顏色由對方主模型的視圖設定決定，需對方在連結顯示設定中改為依連結視圖或自訂。這點需實際測試。

結論：兩種方式都不能保證，建議以**系統類型打底、篩選與視圖樣板控制出圖**，並用 Dynamo 批次複製、轉移專案標準或專案範本 (.rte) 散佈，再把「系統名稱 → RGB」寫進 BEP。
