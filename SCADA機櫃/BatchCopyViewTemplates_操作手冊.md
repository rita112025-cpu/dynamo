# BatchCopyViewTemplates 操作手冊

**版本：** 2026-11-07（台北時間）  
**適用：** Autodesk Revit **2025.5**（繁體中文）＋ Dynamo（**CPython3**、執行模式：**手動**）  
**圖形位置：** `D:\Update Log\Dynamo_BatchViewTemplate\BatchCopyViewTemplates.dyn`  
**對應腳本：** `D:\Update Log\Dynamo_BatchViewTemplate\BatchCopyViewTemplates.py`  
**文件性質：** 實務操作指南（依 2026-11-07 台北實際測試與畫面確認整理）。本手冊不修改任何模型、不執行圖形。

---

## 1. 用途與範圍

本圖形可把**目前作用中來源專案**內指定的**視圖樣板（View Template）**（含樣板所引用的篩選）批次複製到目標資料夾內多個 `.rvt`。

| 項目 | 說明 |
|------|------|
| 正確樣板名稱 | **`SCADA`**（不是 `SCADA 3D`） |
| 測試目標資料夾 | `C:\Users\user\Downloads\VT_Test`（本次測試內含 3 個 `.rvt`） |
| 測試日期 | 2026-11-07（台北）使用者已成功跑通 dry-run 與寫入 |
| 來源專案檔名 | **尚未確認**；**僅憑檔名不足以認定來源**。請以**目前作用中、且實際含已設定完成之 `SCADA` 樣板**的專案為準 |

> **注意：** 較早畫面曾出現 `DN-ESC-0400-0000 v8.3.rvt` 等檔名；檔名本身不能證明該檔即為正確來源。請一律以作用中文件是否實際含 `SCADA` 為準。

## 2. 操作前必讀（安全）

1. **永遠先用測試檔**，且測試檔必須是：
   - **非工作共用（non-workshared）獨立檔**；或
   - 已正確 **Detach** 後另存為**與正式中央模型無關**的獨立檔。  
   **單純複製本機檔案不夠**——若目標仍連到正式中央，`save()` 仍可能同步回原中央。  
   （獨立／非工作共用是**操作前提**；本次 3 個測試檔的實際工作共用狀態**畫面未顯示、尚未確認**。）
2. **禁止**對正式／生產中央模型做測試寫入。
3. 來源專案請先確認 `SCADA` 樣板設定正確，並**儲存來源專案**。
4. **新建／新增**的樣板**不會自動套用**到既有視圖，需手動指定。若目標已有同名樣板而走**覆寫**路徑，程式碼意圖會重指向既有視圖的樣板關聯，但**該路徑尚未實測**。
5. Code Block 寫 `[]` 代表複製**全部**樣板；搭配 `True` 風險高，正式操作請只用 `["SCADA"]`。

## 3. 圖形結構（5 節點／4 連線）

執行模式請維持 **手動**。引擎為 **CPython3**。

| 節點 | 對應 | 設定 |
|------|------|------|
| Directory Path | **IN[0]** | 目標資料夾路徑（測試例：`C:\Users\user\Downloads\VT_Test`） |
| Code Block | **IN[1]** | 樣板名稱清單。正確寫法：`["SCADA"];` |
| Boolean | **IN[2]** | `False`＝乾跑（dry-run）；`True`＝實際寫入 |
| Python Script「Batch Copy View Templates」 | 主程式 | CPython3 |
| Watch「Report」 | 報表 | 顯示結果文字；必要時放大／縮放節點以看完整路徑 |

## 4. 建議完整流程

### 步驟 A — 準備來源

1. 開啟含已設定完成之 **`SCADA`** 視圖樣板的來源專案，並保持為**作用中文件**。
2. 在 Revit：**視圖**索引標籤 → **視圖樣板**下拉 → **管理視圖樣板**，確認清單有 **`SCADA`**。
3. 可點 `SCADA` → **V/G 取代篩選** 檢視篩選啟用狀態（見第 5 節）。
4. **儲存來源專案**後再開 Dynamo 圖形。

### 步驟 B — 設定圖形（先維持 False）

1. 開啟 `BatchCopyViewTemplates.dyn`。
2. Directory Path 選目標測試資料夾。
3. Code Block 設為：

```
["SCADA"];
```

4. Boolean 設為 **`False`**。
5. 按 **執行**，閱讀 Report（Watch）。

**乾跑成功時應看到類似：**

- `Source templates (1): SCADA`
- 接著對**每個**目標各一筆 **`DRY RUN`** 訊息（本次測試為 3 個目標）  
- **不會**開啟／修改目標檔

若出現 `[NOT FOUND in source] …`：樣板名稱錯誤，或作用中文件不是含 `SCADA` 的來源。常見錯誤名稱：`SCADA 3D`。

6. 確認結果正確後，**在 Boolean 仍為 False 時儲存圖形**，保留安全設定。  
7. **兩次執行之間不要切換作用中文件**；來源維持同一個作用中專案。

### 步驟 C — 實際寫入（True）

1. 來源仍為作用中。Boolean 改 **`True`**。
2. 執行一次。
3. Report 中**每個目標**預期為 **OK**：若目標尚無該樣板則為 **added**；若已有同名樣板則為 **overwritten**（**覆寫路徑尚未實測**）。本次測試為 3 個目標皆 **added: SCADA**（未覆寫）。
4. 以畫面／目視確認目標內已有 `SCADA`；綠色圖形覆寫於目標中可見且使用者已確認可接受。  
   （證據來源為螢幕截圖與使用者確認，**非**日誌或 API 遙測。）

### 步驟 D — 寫入後立即復原安全設定

1. Boolean **改回 `False`**。
2. **儲存圖形**（避免下次誤開即寫入）。
3. 可關閉 Dynamo（若需）。

### 步驟 E — 在目標指派樣板並驗證外觀

> **新增**進來的樣板**不會自動套用**到既有視圖。覆寫同名樣板時，程式碼意圖會重指向既有視圖／預設樣板關聯，但**尚未實測**——實務上請仍以手動檢查為準。

1. 開啟測試目標 `.rvt`（應為非工作共用或已 detach、且與正式中央無關的獨立測試檔——此為前提；本次 3 檔實際狀態未由畫面確認）。
2. 選取要檢查的 **3D 視圖**。
3. **性質**面板 → **視圖樣板** → 指定 **`SCADA`**。
4. 目視確認綠色圖形覆寫等結果是否符合預期。
5. **儲存**目標檔。

## 5. 樣板內容與篩選（已知／未驗證）

在 **管理視圖樣板** 中，`SCADA` 可見，且初始檢查時「此樣板指定的視圖數目」可為 **0**（尚未指派視圖屬正常）。

`SCADA` 內含兩個**已啟用／可見**的篩選（名稱）：

- `SCADA`
- `SCADA_電氣設備`

並帶有**綠色圖形覆寫**。篩選條件仰賴專案中使用者參數（如 **服務內容**、**備註**）等；**實際謂詞、類別、比對值未深入檢查**，本手冊標為 **未驗證**，請勿自行假設細節。

**重要：**

- 目標元素必須具備對應參數定義／綁定／數值，篩選才會命中。
- 本腳本**不會**幫元素填寫參數值。
- 複製使用 `CopyElements`＋`UseDestinationTypes`：目標若已有**同名篩選定義**，會**沿用目標既有定義**，**不會更新**目標篩選內容。

## 6. 腳本行為摘要（實務相關）

| 行為 | 說明 | 測試狀態 |
|------|------|----------|
| 乾跑 `False` | 不開啟、不修改目標 | 已確認（畫面） |
| 寫入 `True` 新增樣板 | 各目標 OK、added（本次 3 檔） | 已確認（畫面＋目視） |
| 同名樣板覆寫 | 先更名舊樣板→複製新→重指向既有 `View.ViewTemplateId`／`ViewFamilyType.DefaultTemplateId`→刪舊（單一交易） | **邏輯存在，執行時未測** |
| 更新目標既有同名篩選 | 不會；沿用目標定義 | **未驗證** |
| 略過來源 | 來源本機＋中央本身排除 | 結構已知 |
| 略過目標 | 已開啟／連結文件、中央路徑、備份 `*.0001.rvt`、版本不符等 | 結構已知 |
| 工作共用目標 `save()` | 可能同步回**原中央** | **高風險；獨立檔為操作前提；本次 3 測試檔工作共用狀態未確認** |
| 對話框抑制 | 僅交易 preprocessor；開啟／同步時仍可能跳出提示 | **不可保證無人值守** |
| 嚴重錯誤回復 | 成功路徑有實例化介面；嚴重錯誤 rollback | **未測** |
| 暫存本機清理 | 若 `open_target` 建立本機後拋錯，路徑可能遺失；關閉例外可能略過清理 | **無絕對保證** |

## 7. 疑難排解

### 7.1 Report 出現 `[NOT FOUND in source]`

- Code Block 名稱是否精確為 **`SCADA`**（非 `SCADA 3D`）？
- 作用中文件是否真的含該樣板？
- 若圖形被重設為預設：重新選 Directory Path、名稱，並先保持 **False** 再執行。

### 7.2 `NO TARGET`／找不到檔

- Directory Path 是否指向含 `.rvt` 的資料夾？
- 空資料夾會得到無目標結果；錯誤訊息請以 Report **完整原文**為準。
- Watch 文字常被裁切：請**拉大節點或縮放**以看完整路徑。

### 7.3 執行看似卡住（曾有 overnight 乾跑「像停住」後又完成；原因／時長不明）

1. **不要**在仍可能執行中時重按執行，也**不要**先改成 `True`。
2. 用 **Alt+Tab** 檢查是否有隱藏對話框擋住。
3. **不要**僅憑 CPU 使用率判斷已完成或失敗。
4. 避免強制結束 Revit 或相關行程。
5. 若持續異常且 Dynamo 仍可回應：正常關閉 Dynamo、**儲存模型**，再尋求協助。  
6. 強制結束有遺失未存檔風險。

### 7.4 寫入後畫面沒變化

- 若為**新增**樣板，可能已複製但**尚未指派**到目前視圖。請依步驟 E 在性質中指定 `SCADA`。
- 覆寫路徑雖意圖重指向既有視圖，但**尚未實測**；仍請手動確認指派狀態。
- 元素參數值不符合篩選時，綠色覆寫不會出現（需檢查參數，非腳本自動填值）。

| 檢查項 | 狀態 | 依據 |
|--------|------|------|
| 圖形結構／語法與來源一致 | **PASS** | 先前實際檢視 |

## 9. 快速檢查清單（每次使用）

- [ ] 來源作用中且含 `SCADA`；來源已儲存  
- [ ] 目標為非工作共用或已 detach 的獨立測試檔（無正式中央連線）  
- [ ] Code Block = `["SCADA"];`（不是 `SCADA 3D`，也不是 `[]`）  
- [ ] 先 `False` 執行 → Report 正確（各目標 DRY RUN）→ **存圖形**  
- [ ] 再 `True` 執行 → 各目標 OK（added 或 overwritten）→ Boolean **改回 False** 並存圖形  
- [ ] 開目標 → 3D 視圖性質指派 `SCADA`（新增樣板不會自動套用）→ 目視 → 存檔
